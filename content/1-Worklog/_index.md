This section presents my weekly worklog during the **First Cloud Journey** internship program at Amazon Web Services Vietnam Co., Ltd.

The internship program was completed over **12 weeks**, from **17/04/2026** to **10/07/2026**. During this period, I attended orientation and technical sharing sessions, studied cloud computing concepts, completed practical AWS labs, worked with my group, and completed the final project and internship report.

The activities completed during each week are summarized below:

**Week 1:** [Attend the kickoff session and learn the fundamentals of AWS](1.1-week1/)

**Week 2:** [Join the internship group and learn the workplace and reporting procedures](1.2-week2/)

**Week 3:** [Attend company events and explore practical AWS projects](1.3-week3/)

**Week 4:** [Practice with Amazon EC2, Amazon S3, and AWS IAM](1.4-week4/)

**Week 5:** [Practice AWS Storage Gateway, File Shares, and static website hosting on Amazon S3](1.5-week5/)

**Week 6:** [Configure Amazon CloudFront, S3 Versioning, and cross-Region replication](1.6-week6/)

**Week 7:** [Practice creating IAM Users, Policies, Roles, and Restriction Policies](1.7-week7/)

**Week 8:** [Study AWS architecture, VMware, and virtual machine migration to AWS](1.8-week8/)

**Week 9:** [Test IAM User permission limits and learn about AWS Key Management Service](1.9-week9/)

**Week 10:** [Develop the project idea and connect an on-premises environment with AWS Storage Gateway](1.10-week10/)

**Week 11:** [Complete the project, validate AWS resources, and review cost optimization](1.11-week11/)

**Week 12:** [Review the labs, complete the final report, and conclude the internship program](1.12-week12/)

Maintaining a weekly worklog helped me track my learning progress, review completed tasks, and summarize the knowledge and practical skills gained throughout the internship.
