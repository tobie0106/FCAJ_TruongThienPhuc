During my internship at **Amazon Web Services Vietnam Co., Ltd.** from **17/04/2026** to **10/07/2026**, I had the opportunity to learn about AWS services and apply the knowledge acquired at university to a practical cloud project.

I participated in the **Task Management System** project, in which I designed and documented a serverless architecture using services such as Amazon S3, Amazon CloudFront, Amazon Cognito, AWS AppSync, AWS Lambda, Amazon DynamoDB, Amazon CloudWatch, AWS CodePipeline, AWS CodeBuild, and AWS CloudFormation. Through this project, I improved my skills in cloud computing, system analysis, technical documentation, reporting, communication, and problem-solving.

During the internship, I also prepared a project proposal, developed a step-by-step workshop, translated and summarized an AWS technical blog, maintained weekly worklogs, and published the final report using Hugo and GitHub Pages.

In terms of work ethic, I always tried to complete the assigned tasks carefully, followed the internship program requirements, and actively learned from mentors, technical documents, and community examples. I was also willing to revise my work whenever I received feedback or when the project requirements changed.
